# 🌐 Redes de Computadores II — IFPI/SRN

Repositório destinado ao armazenamento das **aulas, exemplos práticos, códigos, atividades e materiais de apoio** utilizados na disciplina de **Redes de Computadores II** do curso de **Tecnologia em Sistemas para Internet** do **Instituto Federal do Piauí — Campus São Raimundo Nonato**.

## 📚 Sobre a disciplina

A disciplina busca aprofundar conceitos de comunicação em redes por meio de uma abordagem teórica e prática, utilizando ferramentas como **Python, terminal, Wireshark, Mininet e Ryu**.

Ao longo das aulas, os conteúdos são trabalhados com exemplos práticos para facilitar a compreensão de como aplicações se comunicam através de uma rede.

## 🎯 Objetivos

- Compreender o funcionamento da comunicação entre aplicações em rede;
- Entender a relação entre **IP, portas, sockets e protocolos**;
- Desenvolver aplicações cliente-servidor utilizando Python;
- Explorar os protocolos **TCP, UDP, HTTP, HTTPS e DNS**;
- Capturar e analisar tráfego de rede;
- Compreender conceitos de redes definidas por software (**SDN**);
- Utilizar ambientes de simulação e emulação de redes;
- Aplicar os conhecimentos adquiridos no desenvolvimento de projetos práticos.

## 🧩 Conteúdos abordados

Entre os principais assuntos trabalhados na disciplina estão:

- Revisão de IP, portas e modelo cliente-servidor;
- Sockets em Python;
- Comunicação TCP e UDP;
- Fluxo de bytes e definição de protocolos de aplicação;
- HTTP e APIs REST;
- HTTPS e TLS;
- DNS;
- Análise de pacotes com Wireshark;
- Introdução à segurança e análise de tráfego;
- Mininet;
- SDN e OpenFlow;
- Controlador Ryu;
- QoS, NFV e Network Slicing;
- Desenvolvimento de projeto final integrando os conteúdos da disciplina.

## 🚀 Projeto final

Como atividade integradora, os conteúdos da disciplina serão utilizados no desenvolvimento de um projeto envolvendo **monitoramento e análise de tráfego de rede**, combinando conceitos estudados ao longo do semestre.

A proposta envolve a integração de tecnologias como:

```text
Python
  ↓
Sockets / HTTP / DNS
  ↓
Captura e análise de tráfego
  ↓
Wireshark / Mininet
  ↓
SDN / Ryu
  ↓
Sistema de monitoramento
```
